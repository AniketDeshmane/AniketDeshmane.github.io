LinkedIn Experience Calculator

Instantly calculate the total cumulative work experience and career start date for any LinkedIn profile, with smart overlapping-role deduplication.

⬇️ Add to Chrome — It's Free

📺 Watch the Demo

What happens when you use it?

1. You visit a profile: You open a LinkedIn profile normally. The extension quietly notices you're there.

2. The button appears: A shiny new "Calculate" button is seamlessly injected into the page.

3. The Magic Happens: When you click it, the extension reads the dates, merges any overlapping jobs (so you don't over-count), and shows you the true total!

Under the Hood

Curious about what happens internally the millisecond you click that button? Here is the exact internal data flow:

1. DOM Fetcher: The extension silently sends a background request to fetch the user's hidden Experience HTML.

2. Regex Parser: A hyper-optimized Regular Expression scans the raw HTML to extract every single date range (e.g. "Jan 2020 - Present").

3. Interval Engine: The engine converts all those dates into mathematical blocks. It sorts them chronologically and merges any overlapping pieces together!

4. User Interface: The final, perfectly deduplicated total is injected back into your active LinkedIn window.

Awesome Features

  • ⚡ Instant Calculation: Calculates total experience flawlessly in milliseconds.
  • 🧩 Smart Deduplication: Automatically detects and merges overlapping roles so you never over-count concurrent jobs.
  • 🔗 Seamless Integration: Injects natively into the LinkedIn UI directly below the Experience header.
  • 🔒 Privacy First: No tracking, no external servers. Everything runs entirely inside your browser.

Why I Built This

I kept running into the same problem before every interview:

I'd visit a candidate's LinkedIn profile and see 8, 10, sometimes 15+ roles across multiple companies. Overlapping dates. Contract gigs. Parallel positions.

And LinkedIn never shows you the total.

So every single time, I'd sit there manually adding up the years and months, hoping I didn't double-count. It was painful. And it was the same problem every time.

So I decided to scratch my own itch and build a tiny tool that does it in one click. That's how LinkedIn Experience Calculator was born. 🎉

Tech Stack

This extension is built with zero dependencies — no React, no npm, no build step. Just clean, vanilla JavaScript.

  • 📁 6 source modules — cleanly separated by responsibility
  • 📝 ~1,200 lines of code — lean and focused
  • ⚙️ Manifest V3 — the latest Chrome Extension standard
  • 🧩 Content Script Architecture — injects directly into LinkedIn pages
  • 🔍 Regex-based Date Parser — extracts "Jan 2020 - Present" style date ranges
  • 🧮 Interval Merging Engine — deduplicates overlapping employment periods
  • 💾 Chrome Storage API — caches results so repeat visits are instant

Project Structure

LinkedInExp/
├── manifest.json          # Extension config (Manifest V3)
├── icons/                 # Extension icons (16, 48, 128px)
├── styles/
│   └── injected.css       # UI styles injected into LinkedIn
└── src/
    ├── content.js         # Main entry point & URL router
    ├── modules/
    │   ├── domScraper.js  # HTML fetcher & date extractor
    │   ├── uiRenderer.js # Injects results into LinkedIn UI
    │   ├── observer.js   # MutationObserver for SPA navigation
    │   └── storage.js    # Chrome storage cache layer
    └── utils/
        ├── dateParser.js     # Month/year string parser
        └── intervalEngine.js # Overlap merging algorithm
